# Day 10 — Semantic Search

## Built
- semantic_search.py: index documents once, search by meaning per query

## Learned
- Semantic search = find by meaning, not words (built the retrieval core of RAG)
- Two phases: index once (expensive), search per query (cheap)
- Similarity scores are a confidence signal (useful for RAG thresholds)
- How embeddings are trained: a fill-in-the-blank game → meaning emerges as location

## Evidence
- "cheap flights" → "affordable airfare" (0.547), zero shared words
